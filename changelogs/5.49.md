# 5.49.1

Released 29th October 2026.

## Security
- PHP versions vulnerable to [CVE-2026-109618](https://www.cve.org/CVERecord?id=CVE-2026-109618) and [CVE-2026-109619](https://www.cve.org/CVERecord?id=CVE-2026-109619) (PHP2Shell) are no longer accepted. The server now refuses to start unless it runs PHP 8.2.35, 8.3.36, 8.4.27, 8.5.12 or newer within the same branch.
- PHP 8.1 is no longer supported. It is end of life and has no release containing these fixes.
- Updated PHP binaries are available from the PHP-Binaries releases. Extensions built for older PHP binaries (e.g. custom `.dll`/`.so` extensions) may need to be rebuilt.

# 5.49.0

Released 29th October 2026.

**For Minecraft: Bedrock Edition 1.26.60**

This is a support release for Minecraft: Bedrock Edition 1.26.60.

**Plugin compatibility:** Plugins for previous 5.x versions will run unchanged on this release, unless they use internal APIs, reflection, or packages like the `pocketmine\network\mcpe` or `pocketmine\data` namespace.
Do not update plugin minimum API versions unless you need new features added in this release.

**WARNING: If your plugin uses the `pocketmine\network\mcpe` namespace, you're not shielded by API change constraints.**
Consider using the `mcpe-protocol` directive in `plugin.yml` as a constraint if you're using packets directly.

## General
- Added support for Minecraft: Bedrock Edition 1.26.60.
- Removed support for older versions.
- Chorus plants, fire and redstone dust now send the connection states which 1.26.60 clients use to render them. These are calculated the same way as vanilla, and update when neighbouring blocks change.
- Worlds saved by 1.26.50 or older which contain these blocks are upgraded automatically.

## Fixes
- Fixed chorus plants connecting to end stone on their sides. They now only connect to end stone below them, like vanilla.

## API
### `pocketmine\block`
- The following new API methods have been added:
  - `public ChorusPlant->isConnectedAt(int $facing) : bool`
  - `public ChorusPlant->setConnectedAt(int $facing, bool $connected) : $this`
  - `public Fire->isConnectedAt(int $facing) : bool`
  - `public Fire->setConnectedAt(int $facing, bool $connected) : $this`
  - `public RedstoneWire->getConnection(int $facing) : utils\RedstoneWireConnection`
  - `public RedstoneWire->setConnection(int $facing, utils\RedstoneWireConnection $connection) : $this`

### `pocketmine\block\utils`
- The following new enums have been added:
  - `RedstoneWireConnection`
