# 5.45.4
Released 7th August 2026.

## General
- Added a section to the README describing what this fork adds on top of upstream PocketMine-MP.

## Fixes
- Fixed `ChorusPlant` referencing `Facing` without importing it, which caused a fatal error whenever a chorus plant was placed or updated.
- Fixed `BlockSupportRegistry::register()` asserting that the group ID *is* null when registering a group handler, instead of rejecting a null one.
- `BlockSupportRegistry::isTypeSupported()` now takes the supporting block and facing as real parameters instead of a variadic, so handlers which need a facing can no longer be called without one.
- Fixed the bedrock data generation tool crashing on recipes without an unlocking requirement.

# 5.45.3
Released 7th August 2026.

## Fixes
- Added the missing gathering join info to `TransferPacket`. 1.26.40 clients and proxies failed to decode transfers, leaving the player on the old server.
- `ClientboundUpdateSoundDataPacket` now carries the 1.26.40 sound update variants instead of a sound event string.
- Fixed the sub-chunk entry format: terrain data, both height maps and the blob hash are now optionals, and the entry count is a varint.
- Fixed map decoration colours being written as a variable-length RGBA value instead of a fixed ARGB one.
- Fixed map tracked objects gating their actor ID and block position on the object type instead of sending both as optionals.
- Fixed the mine block stack request action writing its stack network ID as a varint instead of a 32-bit integer.
- Fixed the structure editor redstone save mode being written as a varint instead of a byte.
- Removed the damage field from `AnvilDamagePacket`.

# 5.45.2
Released 7th August 2026.

## Fixes
- Skins that don't provide geometry now ship a default humanoid definition. 1.26.40 clients disconnect when a skin's resource patch names a geometry with no matching definition, which affected all plugin-created skins.
- Fixed `PlaySoundPacket` missing the loop count field added in 1.26.40.
- Fixed item stack request slot info reading its slot as a varint instead of a 32-bit integer, which crashed the server when picking up creative items.
- Fixed `CraftRecipeAutoStackRequestAction` and `GrindstoneStackRequestAction` field layouts.
- Added the missing results entry format for `DeprecatedCraftingResultsStackRequestAction`.

# 5.45.1
Released 6th August 2026.

## Fixes
- Scoreboard entries now carry their own type and action ID, and removals use an optional objective name.
- `SetScoreboardIdentityPacket` entries gate the actor unique ID behind an optional instead of the packet type.
- Item stack responses write container info and stack network IDs as optionals.
- Item stack request actions are sent under a variant ID.
- `ClientboundMapItemDataPacket` no longer uses the update bitflag; every section is optional.
- `PlayerLocationPacket` and `PlayerUpdateEntityOverridesPacket` use the reordered 1.26.40 layouts.
- Fixed `PlayerUpdateEntityOverridesPacket` sending a runtime ID where the protocol specifies a unique ID.

# 5.45.0
Released 6th August 2026.

**For Minecraft: Bedrock Edition 1.26.40**

This is a support release for Minecraft: Bedrock Edition 1.26.40.

**Plugin compatibility:** Plugins for previous 5.x versions will run unchanged on this release, unless they use internal APIs, reflection, or packages like the `pocketmine\network\mcpe` or `pocketmine\data` namespace.
Do not update plugin minimum API versions unless you need new features added in this release.

**WARNING: If your plugin uses the `pocketmine\network\mcpe` namespace, you're not shielded by API change constraints.**
Consider using the `mcpe-protocol` directive in `plugin.yml` as a constraint if you're using packets directly.

## General
- Added support for Minecraft: Bedrock Edition 1.26.40.
- Removed support for older versions.
- WaterdogPE support is now optional. Direct connections keep their real IP and XUID, and the server still works behind a proxy.
- `VoxelShapesPacket` is now sent before `StartGamePacket`. The 1.26.40 client resolves block shapes against this registry.

## Fixes
- Item stacks now always write the full structure, including air, instead of being truncated to a single byte.
- Entity metadata entries now carry a payload variant before the type tag.
- `PlayerAuthInputPacket` input flags are now read as a list of set indexes instead of a bitset, fixing block breaking animations and sounds.
- Recipe ingredients in `CraftingDataPacket` now use the name-tagged format, and unlocking requirements are optional with a context enum.
- Fixed the creative group category being written as a 32-bit integer instead of a byte.
- Fixed `MoveActorDeltaPacket` writing a packed flag header instead of per-field presence flags.
- Fixed `NetworkInventoryAction` window ID and source flags not being written as optionals.
- Added the missing null gamerule variant, and fixed integer gamerules being written as varints in `StartGamePacket`.
