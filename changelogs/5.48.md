# 5.48.5

Released 30th September 2026.

## General

- Added the following blocks:
  - Sulfur, Chiseled Sulfur, Polished Sulfur, Sulfur Bricks, and their slabs, stairs, and walls
  - Cinnabar, Chiseled Cinnabar, Polished Cinnabar, Cinnabar Bricks, and their slabs, stairs, and walls
  - Potent Sulfur, including wet, cycling, and continuous geyser behaviour
  - Heavy Core
  - Wool Stairs and Wool Slabs in all colours
  - Concrete Stairs and Concrete Slabs in all colours
  - Shelf Mushroom
  - Red Shrub
- These blocks now appear in the creative inventory and can be used with `/give`.

## API

### `pocketmine\block`

- The following new classes have been added:
  - `ConcreteSlab`
  - `ConcreteStairs`
  - `ContinuousPotentSulfur`
  - `CyclingPotentSulfur`
  - `EruptivePotentSulfur`
  - `HeavyCore`
  - `PotentSulfur`
  - `RedShrub`
  - `ShelfMushroom`
  - `WetPotentSulfur`
  - `WoolSlab`
  - `WoolStairs`
- The following new API methods have been added:
  - `protected Slab->canCombineWith(Slab $slab) : bool`

### `pocketmine\event\block`

- Added `GeyserEruptionPulseEvent`.

## Fixes

- Fixed jukebox record sounds not using the listener range bypass flag, and being played from the corner of the block instead of its centre.
- Fixed slabs of different colours combining into a single double slab.

# 5.48.0

Released 20th September 2026.

**For Minecraft: Bedrock Edition 1.26.50**

This is a support release for Minecraft: Bedrock Edition 1.26.50.

**Plugin compatibility:** Plugins for previous 5.x versions will run unchanged on this release, unless they use internal APIs, reflection, or packages like the `pocketmine\network\mcpe` or `pocketmine\data` namespace.
Do not update plugin minimum API versions unless you need new features added in this release.

**WARNING: If your plugin uses the `pocketmine\network\mcpe` namespace, you're not shielded by API change constraints.**
Consider using the `mcpe-protocol` directive in `plugin.yml` as a constraint if you're using packets directly.

## General
- Added support for Minecraft: Bedrock Edition 1.26.50.
- Removed support for older versions.

## Fixes
- Fixed a crash caused by shift-clicking recipe-book crafting in the player inventory.
