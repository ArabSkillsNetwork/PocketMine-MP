# 5.50.0

Released 7th November 2026.

This release adds NetherNet, the WebRTC based transport Minecraft: Bedrock Edition uses from 1.26.50 onwards, next to RakNet.

**Plugin compatibility:** Plugins for previous 5.x versions will run unchanged on this release, unless they use internal APIs, reflection, or packages like the `pocketmine\network\mcpe` or `pocketmine\data` namespace.
Do not update plugin minimum API versions unless you need new features added in this release.

## General
- Added NetherNet support. Choose the transport with `network.transport` in `pocketmine.yml`:
  - `both` - RakNet and NetherNet side by side (default, also for existing `pocketmine.yml` files without the setting)
  - `raknet` - classic RakNet only, the behaviour of previous versions
  - `nethernet` - NetherNet only
- NetherNet needs the `nethernet` PHP extension. The [ArabSkillsNetwork PHP-Binaries releases](https://github.com/ArabSkillsNetwork/PHP-Binaries/releases) ship it enabled, download the latest one for your PHP version. On a PHP without it the server refuses to start unless `network.transport` is set to `raknet`.
- New `network.nethernet` settings in `pocketmine.yml`: signaling `url`, `tls-cert`/`tls-key` for https, a fixed `ice-port`, `mtu`, `advertise-addresses` for NAT/Docker/cloud hosts, `trusted-proxies` and `real-ip-header` for reverse proxies, the operator key and domain, and `reject-banned`, `reject-not-whitelisted` and `reject-when-full` to refuse players at signaling before any WebRTC setup.
- The setup wizard now asks for the transport, the NetherNet signaling port, the ICE port and an optional TLS certificate/key.
- The NetherNet operator key (`nethernet_operator_key.pem`) is generated on first start. Keep it: clients remember it.
- Added the `laith98dev/nethernet` composer dependency.

## API
### `pocketmine\network\mcpe\nethernet`
- The following new classes have been added:
  - `NetherNetInterface` - `NetworkInterface` serving players over NetherNet
  - `NetherNetPacketSender` - `PacketSender` for NetherNet sessions
